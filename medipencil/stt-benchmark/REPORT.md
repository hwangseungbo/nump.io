# STT 모델 벤치마크 보고서 — MediPencil(MintNote) 받아쓰기 엔진 선정

- 측정일: 2026-10-15 / 장비: nump-intel-server (CPU 전용, 80코어, GPU 없음)
- 음성: 사용자가 test-dialogues.md 시나리오 1을 실제 마이크로 낭독한 녹음 2개
  (MintNote 앱 저장분, 48kHz mono, 합계 75.7초 — 실사용과 동일한 마이크·환경)
- 정답 대본: 시나리오 1 낭독분 (VAD 미적용 large-v3-turbo·Qwen 교차 대조로 발화 범위 확정,
  마지막 "4주 뒤…" 문장은 녹음 종료로 제외)
- 채점: CER(글자 오류율, 정규화 후 — 공백·문장부호 제거, %/mg·한글수사↔숫자 통일),
  의학용어 15개 적중률, RTF(전사시간÷음성길이, CPU 16스레드)

## 핵심 발견

1. **(운영 버그) 기존 어댑터의 VAD(threshold 0.5)가 실제 발화를 통째로 잘라냄.**
   45초 녹음에서 "약은 빠뜨리지 않고 드셨나요? 암로디핀 5밀리그램이랑…" 등
   약 1/3이 무음으로 오판돼 삭제되고 있었음(受信 203자 → 수정 후 296자).
   → threshold 0.2 + min_silence 500ms로 완화, 운영 반영 완료 (2026-10-15).
   무음 환각("감사합니다" 붙는 현상)도 이 설정에서 발생하지 않음을 확인.
2. **한국어 파인튜닝 Qwen(1.7B)이 정확도 압승** — 당화혈색소·142·"잘 때 심해요" 등
   전 모델 중 유일하게 거의 전부 정답. 유일한 약점은 "암로디핀→안로디핀"과 CPU 속도.
3. **whisper large-v3-turbo가 속도·정확도 균형 최적** — medium보다 빠르고 정확.
   당뇨병성·텔미사르탄·암로디핀(2회 중 1회)·식단관리를 모두 잡음.
4. SenseVoiceSmall은 속도는 압도적이나 이 녹음(원거리 마이크 추정)에서 한국어 품질 실격.
5. 모든 모델이 공통으로 틀리는 표기(안로디핀 등)는 모델 교체만으로 해결 불가
   → 어댑터 단 의학용어 교정 사전(후처리) 병행 필요.

## 권고

- **즉시(권장)**: 어댑터 모델을 `small` → `large-v3-turbo`로 교체 (adapter.env 한 줄).
  45초 조각 기준 전사 4→8초 수준으로 체감 지연 소폭 증가, 용어 정확도 대폭 개선.
- **정확도 최우선 대안**: TeamUNIVA 1.7B-ko 전환. 45초 조각당 전사 약 29초로
  받아쓰기 지연이 조각 길이에 근접 — 실시간 받아쓰기엔 부담, GPU 도입 시 최선.
  (병원 납품 사양에 GPU가 들어가면 이 모델로 재평가 권장)
- **병행**: 교정 사전(암로디핀/메트포르민 등 빈발 오인식 목록) 어댑터 후처리 추가.
- 2차 벤치마크: 시나리오 6(자연 구어체, 순환기) 녹음으로 재검 — 대본 준비됨.
