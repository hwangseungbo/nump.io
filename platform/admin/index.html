시연 흐름 팁

  • 기록 승계 가입 — 계정 없는 기존 환자 정보로 회원가입하면 진료기록이 자동 연결됩니다. 예: 강지호 / 1974-02-16 / 01020031006 (전화는 하이픈 없이 입력). 한 글자라도 다르면 새 환자로 생성됩니다.
  • 서류 발급 — patient1이 신청(대상 진료 선택) → doctor1 대시보드 '내 담당 신청'에서 발급 → patient1 서류 목록 [열람]으로 서류 확인·인쇄(PDF 저장).
  • 지시 채널 — doctor1이 환자 검색 EMR에서 지시 작성 → nurse1 대시보드에서 [확인]→[수행] 처리.
  • 재진 제안 — doctor1이 EMR에서 재진 제안 → patient1 예약 탭 '제안된 예약'에서 확정/거절.
  • 수납 결제 — patient1 수납에서 미납 전체 결제(토스 테스트 환경, 실제 청구 없음). 미납이 소진되면 node db/seed-unpaid-bills.js로 보충.
  • 시연 전 데이터 정리 — node db/fix-demo-data.js · node db/seed-demo-refresh.js 실행으로 일정·간호기록을 최신 날짜로 유지.
